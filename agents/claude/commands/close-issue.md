# /close-issue

## 処理フロー

1. **解決根拠の検証**
    - `gh issue view <number>` で内容・再現手順・linked PR を確認する
    - 解決したとされる PR がマージ済みかを確認する（`gh pr view --json state,mergedAt`）
    - 報告されている症状が再現しなくなったことを可能な範囲で確認する（再現手順があれば実行する）

2. **クローズ**
    - 根拠（解決した PR、確認した内容）を1〜3行のコメントで残して `gh issue close` する
    - **未解決・判断できない場合は閉じない**。確認できなかった点を添えてユーザーに報告する

## 注意事項

- 複数 issue の一括クローズを頼まれた場合も1件ずつ検証する
- 自分に管理権限のないリポジトリ（外部 OSS）では勝手に閉じず、検証結果をユーザーに報告して判断を仰ぐ
