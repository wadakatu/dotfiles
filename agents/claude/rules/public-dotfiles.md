# dotfiles は公開リポジトリ

- dotfiles は公開の個人リポジトリで、勤務先の仕事とは関係が無い。ユーザーが試したい個人の道具はここに置いてよいが、汎用に書く。
  対象のリポは引数や設定で受け取り、勤務先のリポ名・ローカルの作業パス・issue / PR 番号・内部のツールの ID・仕事のリポのスクリプトの中身を書かない
- 勤務先に固有の設定（どのリポを対象にするか、パスなど）は公開リポの外に置く。追跡しないローカルの設定ファイルか、仕事のリポに置く
- dotfiles に書く前に、差分を勤務先の名前やリポ名で `git grep -i` / `git diff | rg -i` して、何も出ないことを確かめる

**Why:** 個人の道具の設計を、仕事のリポの具体的な情報を埋め込んだまま dotfiles に書いてマージし、ユーザーに指摘された。
その道具は個人の実験だったので、直し方は仕事のリポへ移すことではなく、汎用に書き直すことだった。
