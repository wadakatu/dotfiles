# セッションの外のリポジトリにコミットする

セッションの cwd とは別のリポジトリ（ユーザーも同じチェックアウトで作業しているもの）にコミットするときは、
`git worktree add <scratchpad>/wt/<name> <branch>` で隔離した作業ツリーを作り、そこで add / commit / push する。
終わったら `git worktree remove` する。ユーザーのチェックアウトとそのブランチには触れない。
隔離できないときでも、各コミットの直前に `git -C <dir> branch --show-current` を確かめる。

branch-guard フックはセッション cwd の HEAD を見るので、別リポジトリの git 操作は `git -C <dir> ...` で書く（フックは `-C` を解釈し、`cd` は解釈しない）。

**Why:** こちらの作業中に、ユーザーが端末側でそのリポジトリのブランチを切り替えたり rebase したりする。別リポジトリなので、こちらからは見えない。
2 つのコミットの間にブランチが切り替わり、2 つ目のコミットが他人の feature ブランチに乗って push され、無関係な open PR に変更が混ざったことがある。
