# サブエージェントを並列に回すとき

worktree 分離で並列に回すときは、ディスパッチのプロンプトに最初から次を入れる。

- 作業ファイルは `<scratchpad>/<エージェント固有の名前>/` に置かせる（scratchpad は共有）。
- テスト DB などの共有資源は、設定ファイルでの固定を確かめてから分ける。
- ファイルを消したら autoloader / classmap を作り直させる。
- 同時の `git switch -c` は upstream 設定だけ失敗しうる（push で直る）。

報告されたテスト件数は参考値。本線は CI の緑と、全ブランチを merge した統合 worktree での全ゲート。

**Why:** 偽の赤と他人の件数の取り違えで、並列の速さが相殺された。
