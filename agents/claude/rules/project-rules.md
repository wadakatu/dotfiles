# プロジェクトの rules は編集の前に自分で開く

リポジトリの `.claude/rules/*.md`（パス別の規約）は、自動で添付されるのを待たずに読む。

- 編集する前に `ls .claude/rules/` で一覧を見て、frontmatter の `paths` が触るパスに一致するものを開く。
- 適用範囲は frontmatter の `paths` が正。CLAUDE.md や AGENTS.md の要約は、範囲を狭く書いていることがある。
- 自動で添付される system-reminder は、一致するファイルを Read したときに付き、Edit だけでは付かないことがある。添付が無いことは「対象外」の根拠にならない。
- 先行ファイルの実装パターンは踏襲してよいが、コメントは引き写さない。規約ができる前に書かれたコメントのことがあるので、コピーしたら規約に照らして削り直す。

**Why:** 要約に「`app/**` の編集時に自動適用」としか書かれていなかったので、コメント規約を読まずに migration を書いた。コメント 80 行・ロジック 50 行の差分を出して、「コメントが長くないか、ちゃんと読み込んでいるか」と指摘された。実際の `paths` には `database/**` や `docker/**` も入っていた。2 日後にも、同じ規約・同じパスで読み飛ばした。そのときは 4 回続けた Edit のどれにも規約が添付されず、指摘を受けた後の Read で初めて添付された。
