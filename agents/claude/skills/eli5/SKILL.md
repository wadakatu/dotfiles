# eli5

前提知識がまったくない人に向けて、**大きな絵と少ない言葉**で説明する HTML を作る。

Topic: $ARGUMENTS

## 言語

**本文はすべて日本語で書く。** 見出し・キャプション・図中のラベルも日本語。

例外は原語のままにする:

- 技術用語・製品名・プロトコル名（TCP, OAuth, Docker, React …）
- コード・コマンド・識別子・ファイルパス
- 保存時のファイル名とカテゴリ名（英語 kebab-case。`eli5-archive` 参照）

日本語に訳すと逆に分かりにくくなる語を無理に訳さない。初出時だけ
「ハンドシェイク（handshake）」のように括弧で原語を添える程度に留める。

## 作り方

- 文字より図。1 画面に 1 つの考えだけ。
- たとえ話を先に出して、正確な用語は後から重ねる。
- 1 文は短く。専門用語を使うときは必ずその場で言い換える。
- HTML の Artifact として publish する。

## 作ったら必ず保存する

生成・publish したら、**同じターン内で `eli5-archive` スキルを実行する**。
カテゴリ分けして `wadakatu/eli5` リポジトリに保存し、公開 URL を返すところまでが一連の流れ。
publish だけで終わらせない。
